# Changelog

All notable changes to this skill will be documented here.

## 1.0.1

- The description now says the skill can request ad account changes, which a person must confirm inside LeadJourney.
- Tracking setup explains what the script collects and checks the site's cookie consent setup before installing it.
- The skill triggers only on LeadJourney reports and dashboards, not on any reporting request.

## 1.0.0 — initial release

- Connects OpenClaw to LeadJourney's hosted MCP server (`https://api.leadjourney.io/mcp`) with OAuth sign-in, no API key.
- Guidance for workspaces, reports, leads, live ad platform data, ad change requests and tracking setup.
